# BlinkIT Grocery Data Analysis & Power BI Dashboard

## Project Overview

This project analyzes BlinkIT grocery sales data to identify sales patterns, top-performing product categories, outlet performance, customer ratings, and other business insights.

The project started with data cleaning and exploratory analysis in Excel and was then developed into an interactive Power BI dashboard.

The goal is to transform raw grocery sales data into meaningful insights that can support business decision-making.

---

##  Business Questions

The analysis focuses on answering questions such as:

- What are the total and average sales?
- Which product categories generate the most sales?
- Which outlet types perform best?
- Which outlet locations generate the highest sales?
- How does outlet size relate to sales?
- What is the distribution of customer ratings?
- How does fat content relate to sales performance?
- Which areas or product categories should receive more attention?
